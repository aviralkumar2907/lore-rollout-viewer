# LOrE rollout viewer

Interactive viewer of six recorded MR V3 SFT rollouts. Select an example, round, and proposed direction to inspect its execution and final answer. This displays recorded outputs, not live model inference.

Website: https://aviralkumar2907.github.io/lore-rollout-viewer/

`index.html` is the browser viewer. `content.html` is the PowerPoint content add-in entrypoint and loads the official Office.js runtime. The viewer requests Restricted permission and does not read or modify slide content. Internet is required for this hosted version.

See SOURCES.txt for data and library attribution.
